## Project title

Silverstone 2024: F1 Race Performance Analysis with SQL

## Status

## Suggested project description

An independent Business Information Systems portfolio project using public 2024 British Grand Prix data. I built a reproducible SQL Server database in Docker, explored six related tables, validated joins and `NULL` handling, and developed a documented cleaned-lap method for comparing pace and consistency. The SQL work uses joins, grouped aggregates, CTEs, `NOT EXISTS`, standard deviation and ranking functions while keeping assumptions and data limitations explicit.

I used AI transparently as an on-demand tutor and debugging partner. I questioned the suggestions, corrected my own queries and made sure I could explain the finished SQL. A Tableau dashboard is being developed as the final presentation layer, so this project is not yet ready for a public feed post.

Race timing, result and pit-stop data: Jolpica F1 API, used under CC BY-NC-SA 4.0. Independent educational analysis; not affiliated with Formula 1 or any team.
